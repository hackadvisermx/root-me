## Solución

1. Formatear el código y ubicar la función que procesa el valor introducido.
2. Renombrar mentalmente o en una copia local las variables y resolver los índices del arreglo de cadenas.
3. Usar breakpoints o la consola de la instancia para observar el valor antes de la comparación final.
4. Validar el resultado solo en Root-Me.
